# My Glossary

学んだ言葉を、使える形で少しずつ残す個人用語集。

## 方針

- 最初から大量登録しない
- 学んだ言葉だけを追加する
- 「一言で / もう少し詳しく / 具体例 / なぜ覚えた？ / 関連語」で残す
- 検索を主役にしつつ、最近学んだ言葉を学習ログとして見せる
- UI用語は、意味をつかみやすい簡易サンプルを付ける
- 動かせるサンプルは、できるだけ実際に触って挙動を確かめられるようにする
- 「ランダムに1語」と「ミニクイズ」で、読むだけでなく思い出す機会を作る
- ジャンルは固定階層ではなくタグで横断する
- 関連語は当面シンプルなリンク。比較モードは作らず、将来の拡張用データ構造だけ維持する

## 復習

トップページの「思い出す」から2種類の復習ができる。

- **ランダムに1語**: 登録済み用語から1語を開く
- **ミニクイズ**: 説明または簡易UIサンプルを見て、4択から用語を当てる

## 用語の追加

1. ページ右上の「＋ 用語を追加」を開く
2. 必要項目を入力する
3. 「JSONを作る」を押す
4. JSONをコピーする
5. `data/terms.json` の配列末尾へ追記する

`context`（なぜ覚えた？）は任意。

## データ例

```json
{
  "id": "tooltip",
  "term": "ツールチップ",
  "english": "Tooltip",
  "reading": "つーるちっぷ",
  "oneLine": "短い説明",
  "detail": "もう少し詳しい説明",
  "example": "具体例",
  "context": "覚えたきっかけ",
  "learnedAt": "2026-08-17",
  "tags": ["Web", "UI"],
  "related": [],
  "relations": {
    "similar": [],
    "contrast": []
  },
  "visual": "tooltip",
  "sources": [
    {
      "label": "参考資料名",
      "url": "https://example.com"
    }
  ]
}
```

`visual` はサンプル表示がある用語だけ指定する。`sources` は定義確認に使った一次資料・公式資料を残すための欄。

## ファイル構成

- `index.html`: ページ構造
- `styles.css`: 基本UI
- `visuals.css`: 用語サンプルの見た目
- `app.js`: 用語検索・詳細・追加JSON生成
- `learning.css`: 復習UIと操作サンプル用スタイル
- `learning.js`: ランダム復習・クイズ・サンプル操作
- `data/terms.json`: 用語データ

## ローカル確認

JSONを `fetch()` しているため、HTMLファイルを直接開くのではなく簡易HTTPサーバーを使う。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開く。
