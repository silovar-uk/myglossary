# My Glossary

学んだ言葉を、使える形で少しずつ残す個人用語集。

## 方針

- 最初から大量登録しない
- 学んだ言葉だけを追加する
- 「一言で / もう少し詳しく / 具体例 / なぜ覚えた？ / 関連語」で残す
- 必要な用語だけ「よくある勘違い」を任意で残す
- 検索を主役にしつつ、最近学んだ言葉を学習ログとして見せる
- トップでは「最近追加 / お気に入り / 今日の1語」をまとめ、日常的に使いやすくする
- UI用語は、意味をつかみやすい簡易サンプルを付ける
- 動かせるサンプルは、できるだけ実際に触って挙動を確かめられるようにする
- 「ランダムに1語」と「ミニクイズ」で、読むだけでなく思い出す機会を作る
- 分類は階層で持ち、タグは横断検索用として残す
- 関連語は当面シンプルなリンク。比較モードは作らない

## トップダッシュボード

検索の直下に、普段使う情報をまとめる。

- **最近追加**: 直近で学んだ用語
- **お気に入り**: ブラウザに保存した★用語
- **今日の1語**: 日付をもとに、その日は同じ1語を表示

大きな管理画面にするのではなく、「開いたらすぐ探せる・戻れる・1語思い出せる」ことを優先する。

## 分類

分類は階層で持つ。

例：

`Web → UI → ナビゲーション`

既存語は `data/categories.json` で分類パスを管理する。今後の新規語は、用語JSONに `categoryPath` を直接持たせてもよい。

タグは階層分類とは別に、横断検索・絞り込み用として残す。

## お気に入り

用語詳細から `★ お気に入り` を付けられる。

- お気に入り情報はブラウザの `localStorage` に保存
- GitHubや外部サーバーへは送信しない
- 「お気に入りのみ」で絞り込み可能
- トップダッシュボードにも反映する

## よくある勘違い

すべての用語には付けない。

誤解しやすい用語だけ `misconception` を任意で持たせ、詳細画面に「よくある勘違い」として表示する。

例：

`プレースホルダーは、入力欄のラベルそのものの代わりではない。`

## 出典

出典は必須条件にしない。気軽に用語を追加できることを優先する。

ただし、定義を確認した用語は MDN / W3C / 公式ドキュメントなど一次情報をできるだけ1件残す。用語追加フォームには、任意の参考元名・参考URL欄を用意する。

## 復習

トップページの「思い出す」から2種類の復習ができる。

- **ランダムに1語**: 登録済み用語から1語を開く
- **ミニクイズ**: 説明または簡易UIサンプルを見て、4択から用語を当てる

## 今後の用語追加の標準運用

用語名だけ指定された場合も、原則として追加前にこちらで必要な情報を補完する。

- 定義
- 一言説明
- 詳細説明
- 具体例
- 階層分類
- タグ
- 関連語
- 必要なら「よくある勘違い」
- 取得できる場合は一次情報・公式資料の出典
- UI用語など、視覚化が有効なら簡易サンプル

出典が見つからないことだけを理由に登録を止めない。意味が複数あって追加対象を特定できない場合を除き、毎回の確認質問は不要とする。

## 用語の追加

1. ページ右上の「＋ 用語を追加」を開く
2. 必要項目を入力する
3. 必要に応じて「よくある勘違い」・分類・参考URLも入力する
4. 「JSONを作る」を押す
5. JSONをコピーする
6. `data/terms.json` の配列末尾へ追記する

`context`（なぜ覚えた？）、`misconception`（よくある勘違い）、`sources`（出典）は任意。

## データ例

```json
{
  "id": "breadcrumb",
  "term": "パンくずリスト",
  "english": "Breadcrumb",
  "reading": "ぱんくずりすと",
  "oneLine": "現在位置までの階層を示すナビゲーション。",
  "detail": "もう少し詳しい説明",
  "example": "ホーム › チケット › 購入方法",
  "misconception": "ページ内の現在位置を示すものだが、主ナビゲーションそのものを置き換えるものではない。",
  "context": "",
  "learnedAt": "2026-08-17",
  "tags": ["Web", "UI", "ナビゲーション"],
  "categoryPath": ["Web", "UI", "ナビゲーション"],
  "related": [],
  "relations": {
    "similar": [],
    "contrast": []
  },
  "visual": "breadcrumb",
  "sources": [
    {
      "label": "W3C WAI-ARIA APG",
      "url": "https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/"
    }
  ]
}
```

`visual` はサンプル表示がある用語だけ指定する。`misconception` と `sources` は任意。

## ファイル構成

- `index.html`: ページ構造
- `styles.css`: 基本UI
- `visuals.css`: 用語サンプルの見た目
- `app.js`: 用語検索・詳細・追加JSON生成
- `learning.css`: 復習UIと操作サンプル用スタイル
- `learning.js`: ランダム復習・クイズ・サンプル操作
- `taxonomy.css`: 階層分類・お気に入りUI
- `taxonomy.js`: 階層分類・お気に入り・追加フォーム拡張
- `dashboard.css`: トップダッシュボード・勘違い表示のスタイル
- `dashboard.js`: お気に入りプレビュー・今日の1語・勘違い欄の拡張
- `data/terms.json`: 用語データ
- `data/categories.json`: 既存語の分類パス

## ローカル確認

JSONを `fetch()` しているため、HTMLファイルを直接開くのではなく簡易HTTPサーバーを使う。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開く。
