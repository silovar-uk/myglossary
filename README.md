# My Glossary

学んだ言葉を、使える形で少しずつ残す個人用語集。

## 方針

- 最初から大量登録しない
- 学んだ言葉だけを追加する
- 「一言で / もう少し詳しく / 具体例 / なぜ覚えた？ / 関連語」で残す
- 検索を主役にしつつ、最近学んだ言葉を学習ログとして見せる
- ジャンルは固定階層ではなくタグで横断する
- 関連語は当面シンプルなリンク。将来の類似・対比・関連図に拡張できるデータ構造にする

## 用語の追加

1. ページ右上の「＋ 用語を追加」を開く
2. 必要項目を入力する
3. 「JSONを作る」を押す
4. JSONをコピーする
5. `data/terms.json` の配列末尾へ追記する

`context`（なぜ覚えた？）は任意。

## データ例

```json
{
  "id": "tooltip",
  "term": "ツールチップ",
  "english": "Tooltip",
  "reading": "つーるちっぷ",
  "oneLine": "短い説明",
  "detail": "もう少し詳しい説明",
  "example": "具体例",
  "context": "覚えたきっかけ",
  "learnedAt": "2026-08-17",
  "tags": ["Web", "UI"],
  "related": [],
  "relations": {
    "similar": [],
    "contrast": []
  }
}
```

## ローカル確認

JSONを `fetch()` しているため、HTMLファイルを直接開くのではなく簡易HTTPサーバーを使う。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開く。
